Field Asset Capture App

User Manual

info 1. Overview

The Field Asset Capture app is a web-based tool designed for field technicians to capture asset photos with embedded GPS coordinates and metadata. The app works offline, storing all data locally until you're ready to export it.

play_arrow 3. Getting Started

3.1 Accessing the App

  • Open the app in a modern browser (Chrome, Edge, Firefox, or Safari recommended)
  • Grant camera and location permissions when prompted

3.2 Interface Overview

  • Camera View - Shows live camera feed
  • Capture Button - Large yellow button to take photos
    • li>Control Buttons - Switch camera, toggle flash, export options li>Status Bar - Shows camera, GPS, and record count status
  • Asset Form - Appears after capturing a photo
  • Instructions Panel - Quick reference guide

check_circle

4.1 Capturing Assets

  • Ensure GPS status shows "Active" (green icon)
  • Point camera at the asset you want to document
  • Tap the yellow camera button to capture
  • Complete the asset details form:
    • Asset Number (required)
    • Description (required)
    • Notes (optional)
  • Click "Save Asset with GPS"

4.2 Camera Controls

  • Switch Camera: Toggle between front and rear cameras
  • Flash: Turn flash on/off (if supported by device)
  • Retry Camera: If camera access fails, use this to retry

4.3 Exporting Data

When you're back online or need to share your data:

  • Export CSV: Creates a spreadsheet with all asset metadata
    • Includes: ID, asset number, description, GPS coordinates, timestamp
  • Export Images: Downloads all captured images with embedded metadata
    • Images are named with asset ID and number
    • Each image contains visual metadata at the bottom

gps_fixed 5. GPS Functionality

  • The app continuously tracks your location
  • GPS accuracy is displayed in meters (lower is better)
  • Green icon indicates active GPS lock
  • Red icon indicates GPS issues (check device settings)

build 6. Troubleshooting

6.1 Camera Issues

If camera doesn't start:

  • Check browser permissions
  • Click "Retry Camera" button
  • Ensure no other app is using the camera
  • Restart your device if problems persist

6.2 GPS Problems

If GPS won't lock:

  • Move to an area with clear sky view
  • Check device location settings
  • Ensure location services are enabled
  • Wait 1-2 minutes for initial lock

storage 7. Data Management

  • All data is stored locally in your browser
To prevent data loss:
  • Export regularly
  • Don't clear browser storage
  • Use the same device/browser for continued access

thumb_up 8. Best Practices

  • Verify GPS accuracy before capturing critical assets
  • Use descriptive asset numbers for easy reference
  • Add detailed notes when the situation is complex
  • Export data at the end of each work session
  • For large projects, export periodically as backup

devices
